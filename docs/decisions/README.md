# Decisions

This is the durable rationale route for `aoa-models` owner, object, lifecycle,
evidence, schema, and consumer-boundary choices.

Canonical records use `AOA-MODELS-D-####-short-slug.md`. Start from
[TEMPLATE.md](TEMPLATE.md), then rebuild
[`generated/decision-index.md`](../../generated/decision-index.md).

Decision records explain why a boundary was chosen. Model records under
`source/` remain stronger for current model meaning; schemas remain stronger
for machine shape; runtime and proof retain their external owners.
